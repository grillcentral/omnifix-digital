# AGENTS.md

Regras para agentes trabalhando no projeto OmniFix Digital / Viatec.

- Nunca usar Base44.
- Nunca usar codigo legado Base44.
- Manter arquitetura modular.
- Criar componentes reutilizaveis.
- TailwindCSS e obrigatorio para UI.
- Preservar visual industrial premium em preto, cinza escuro e laranja.
- Usar React Query para dados remotos ou mockados.
- Preparar toda integracao para backend REST futuro.
- Nao misturar logica de dados com UI.
- Manter codigo limpo, organizado e facil de substituir por API real.
